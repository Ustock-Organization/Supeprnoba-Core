# MM(마켓메이커) 개선 설계 — 리서치 3종 종합 (2026-08-12)

> 근거: ①게임경제·예측시장 유계손실 MM ②실거래소 오더북 MM 실무 ③합성 시장데이터 기법
> (웹 리서치 에이전트 3기 보고, 출처는 각 보고서 원문 — 세션 기록 참조)

## 설계 원칙 전환 (3줄)

1. **가격을 그리지 말고 주문 흐름을 만들어 가격이 창발하게 하라** — bid-ask bounce·미시구조
   노이즈·가격 충격이 공짜로 따라오고, 차트의 인위성이 사라진다.
2. **봇의 손실(=가상화폐 발권)은 수식으로 유계여야 한다** — 심볼별 예산 y₀를 시드한 CPMM(x·y=k)
   백스톱은 y₀ 이상을 구조적으로 지급할 수 없다. "결정론적 가격 + 무한 예산" 봇은 게임 경제
   역사상 예외 없이 무한 발권 익스플로잇으로 끝났다(EVE 광석 NPC 삭제 사례).
3. **MM의 목표는 "가격 조종"이 아니라 "재고 중립 + 스프레드"** — 반응형이 되는 순간 유저가
   패턴을 예측할 수 없게 되고, 대량 매집 자체가 진입가를 악화시켜 무위험 차익이 사라진다.

## 구현 로드맵 (파일 단위)

### M1 — 체결 피드백 루프 + 안전장치 [최우선 전제]
- [x] **(cross-repo) Supernoba-back `fill_processor.cpp`**: MM 측 체결 시
      `mm:inventory:{SYMBOL}` 갱신. ✅ **완료(back main `1f5e850`)** — RedisClient.recordMmInventory
      (GET-modify-SET 원자, inventory.mjs 스키마 유지) + processFill에서 정확히 한쪽만 MM인 체결 갱신.
      검증: mm_inventory_test 14 PASS(실 redis) + 전체 빌드. → 5단계 방어선 활성화.
- [ ] **mm-service 킬스위치 = Deribit MMP형**: 롤링 윈도우(interval) 내 체결수량/순델타 한도 초과
      → 봇 전체가 아니라 **해당 심볼만 frozen_time 동결 후 자동 복귀** (유동성 전멸 방지)
- [ ] **filled_order_delay**(기본 60s): 체결 직후 재호가 대기 — 한 방향 연속 체결 쏠림 1차 방어
- [ ] 호가 최소 존치 시간(0.5s+)·`order_refresh_tolerance` — 과도한 cancel/replace 억제

### M2 — legacy_sine 대체: `organic` 전략 (가격 프로세스 + 주문 흐름)
- [ ] `_calculatePrice()` 교체: 사인파 → **OU 정확해 + Hawkes 변조 점프**
      `Y' = Y·e^(−λΔt) + Ȳ(1−e^(−λΔt)) + σ√((1−e^(−2λΔt))/2λ)·Z`
      파라미터 매핑으로 하위호환: `Ȳ=basePrice`, `σ = amplitude·basePrice·√(2λ)`
- [ ] 레짐 전환(3-state CTMC: bull/bear/range)이 OU 중심선을 이동 — 고점/저점 암기 원천 차단
- [ ] **주문 크기 분포**: 고정 `tradeQuantity` → 라운드넘버 군집({1,10,50,100,…} Dirac) + 기하 꼬리
      (균등난수는 그 자체가 봇 시그니처 — Benford 통과 필수)
- [ ] **MM ID 풀 분리**: `mm-buyer`/`mm-seller` 2종 → `mm-agent-{0..N}` 풀, ZI-C 규칙
      (랜덤 예약가 제약 내 무작위 호가)로 독립 발주 → 자가체결 비율 <5%
- [ ] 취소 흐름 추가(주문 수명 멱함수) — 호가창이 "살아있게"

### M3 — 재고 스큐 활성화 (M1 완료 시 자동 + 보강)
- [ ] spread 전략: AS `reservation = mid − skew·q` — 피드백 연결로 자동 활성
- [ ] Hummingbot 선형보간 수량 스큐(`bid_adj + ask_adj = 2.0`, 밴드 경계에서 한쪽 0) 추가
- [ ] 유저 포지션 인지 스큐(L5): 특정 유저 대량 매집 감지 시 해당 방향 호가 후퇴

### M4 — CPMM 백스톱 (유계 손실, Vertex 하이브리드)
- [ ] 심볼별 가상 준비금 (x₀, y₀) 설정 — **y₀ = 그 심볼의 총 발권 예산(하드 캡)**
- [ ] 곡선 가격 ±슬리피지를 오더북 지정가로 투사(N레벨), 체결 시 준비금 갱신
- [ ] 신규 인플루언서 상장: pump.fun식 가상 준비금으로 시작가 형성(실예산 소모 없음)
- [ ] 예산 소진 시 매수호가 자동 철회(매도만 유지 = 싱크로 전환, EVE 비대칭 원칙)
- [ ] **기준가는 외생 신호(인플루언서 지표)에만 앵커** — 자기 체결가 참조 금지(Mango Markets 교훈)

### M5 — 검증 하네스 (완료 판정 기준)
- [ ] FFT(가격): 지배적 단일 피크 없음 (사인파 잔재 기계 판정)
- [ ] Benford χ²(체결 크기 첫 유효숫자) p > 0.05, 자가체결 비율 < 5%
- [ ] 1분 수익률 초과첨도 ∈ [10, 1000], ACF(r, lag1) < 0, ACF(|r|) 장기 유의
- [ ] corr(거래량, |수익률|) > 0.3
- [ ] 그리드 전략 백테스트 Sharpe < 2.0 (무위험 차익 부재 확인)
